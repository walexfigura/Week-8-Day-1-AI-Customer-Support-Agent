# Common Resolutions

## Purpose

Standard resolutions for the most frequent ticket types, so customers get
consistent answers. Each resolution follows the official policies; it does not
add new rules.

## Quick answer

Find the situation below, use the listed resolution, and note who must approve
anything involving money or order changes.

## Detailed procedure

| Situation | Standard resolution | Needs human approval? |
|---|---|---|
| Order in transit, on track | Share tracking number, carrier, latest scan, estimated delivery. | No |
| Order not yet shipped | Explain processing time (1–2 business days) + transit time for the method. | No |
| Partial shipment / backorder | Explain which items shipped, tracking for each, restock date for the rest. | No |
| Late, still moving | Apologize, share latest scan, explain the trace and lost-package timeline. | No |
| No movement 5+ business days | Open a carrier trace; promise an update within 2 business days. | Support Lead opens trace |
| Presumed lost (10+ business days past estimate) | Offer replacement or refund including shipping fee. | **Yes** |
| Delivered, not received, < 48 h | Ask the customer to wait 48 h and check property, neighbors, mailroom. | No |
| Delivered, not received, ≥ 48 h | File carrier claim; offer replacement or refund. | **Yes** |
| Change-of-mind return, in window | Send to returns portal; mention $6.95 label fee. | No |
| Exchange, in window | Send to returns portal, "Exchange" option; free label for first exchange. | No |
| Damaged/defective, ≤ 14 days | Free replacement or refund; ask for photo. | **Yes** |
| Defective, after 14 days, in warranty | Start a warranty claim with the Warranty Team. | Warranty Team decides |
| Outside return window / final sale | Explain the policy; mention warranty if defective. | Only for an explicit exception request |
| Refund status, refund recorded | Give refund date and amount; banks take 3–10 business days. | No |
| Cancel or change address before shipment | Pass to Support Lead; do not promise it is possible. | **Yes** |
| Product troubleshooting | Walk through documented steps; then warranty/return. | No |

## Common questions

- *"Can you just send me a new one?"* — We can request a replacement where policy
  allows; a team member confirms it.

## Relevant exceptions

- Repeat-contact customers (3+ messages on one issue) get a high-priority escalation
  even when the resolution itself is standard.

## When to escalate

Any row marked **Yes**, plus everything in the escalation guide.
