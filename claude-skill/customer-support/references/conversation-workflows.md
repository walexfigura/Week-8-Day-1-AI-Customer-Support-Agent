## Order inquiry

Order number? → no: ask. Yes: look up (owner must match) → explain status:
unfulfilled (processing time) · partially fulfilled (what shipped, backorder
date) · on track (tracking + estimate) · late (apologize, latest scan, explain
trace timeline) · trace needed / presumed lost (escalate, request approval) ·
delivered but missing (<48 h wait; ≥48 h claim + approval).

## Returns & refunds

Calculate eligibility per item from the delivery date. Eligible → explain the
returns portal and fee. Not eligible → explain the specific reason, offer the
warranty if defective. Refund status → give recorded date and amount, explain
bank timing. Refund demand → only request approval when policy supports it.

## Frustrated customer

Read the full history first. Count contacts; check for broken promises.
Acknowledge specifically, state facts, give next step and owner. Escalate (high)
for 3+ contacts, unkept promises, refund requests, or requests for a manager.

## Product questions

Answer from the product record/FAQ; quote exact specs. Troubleshoot with the
documented steps. Safety symptoms (heat, swelling, burning smell) → stop
troubleshooting, tell them to stop using it, escalate urgent.

## Ambiguous / follow-up

Missing info → ask one clear question, answer what you can. Several questions →
answer each in order. Follow-ups → don't re-ask; continue the earlier workflow.
Explicit human request → always escalate.
